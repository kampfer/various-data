# Spec Delta

## Purpose

定义新浪财经快讯与央行公开市场公告的抓取、解析与入库行为，使这两类数据的采集在失败时明确判错、无新数据时明确成功、重复执行时不产生重复记录。

## ADDED Requirements

### Requirement: 增量抓取

两个抓取任务 MUST 基于已入库的最新记录做增量抓取，MUST NOT 每次全量重复拉取。

#### Scenario: 快讯增量

- **WHEN** 数据库中已有新浪快讯记录
- **THEN** 任务以已入库的最大新浪 id 为起点，只抓取更新的条目

#### Scenario: 快讯首次运行

- **WHEN** 数据库中没有任何新浪快讯记录
- **THEN** 任务抓取最新一页并入库

#### Scenario: 公告增量

- **WHEN** 数据库中已记录最新公告名称
- **THEN** 任务只抓取该公告之后的新公告

### Requirement: 上游请求必须设置超时并校验状态码

所有上游请求 MUST 设置连接与读取超时，MUST 校验 HTTP 状态码；超时或非成功状态码 MUST 使该次执行失败，MUST NOT 无限期挂起。

#### Scenario: 请求超时

- **WHEN** 上游在声明的超时时间内没有响应
- **THEN** 该次执行失败并记录超时原因

#### Scenario: 返回错误状态码

- **WHEN** 上游返回 4xx 或 5xx
- **THEN** 该次执行失败并记录状态码，不继续解析响应内容

### Requirement: 有新数据但解析为空必须判失败

上游确认存在新数据，但解析后没有产生任何可入库记录时，该次执行 MUST 失败。

#### Scenario: 公告版式变化

- **WHEN** 发现新公告但表格解析结果为空
- **THEN** 该次执行失败，并在错误信息中说明公告标题

#### Scenario: 没有新数据

- **WHEN** 上游请求成功但确实没有需要入库的新条目
- **THEN** 该次执行成功结束，不视为失败

### Requirement: 入库必须幂等

同一批数据重复执行 MUST NOT 产生重复记录。

#### Scenario: 连续执行两次快讯抓取

- **WHEN** 在不产生新快讯的时间段连续执行两次
- **THEN** 第二次不新增任何记录

#### Scenario: 重复抓取同一公告

- **WHEN** 同一公告被重复抓取并解析
- **THEN** 已存在的记录不被重复写入

### Requirement: 标题格式差异不影响公告解析

公告表格的标题可能出现期限前缀、隔夜品种或与正文句子合并等形式；解析 MUST 依据交易类型关键字归类，MUST NOT 要求标题与固定字符串完全一致。

#### Scenario: 标题带期限前缀

- **WHEN** 表格标题为"7天期逆回购操作情况"
- **THEN** 该表格被识别为逆回购并正常入库

#### Scenario: 隔夜品种

- **WHEN** 公告出现"隔夜逆回购操作情况"
- **THEN** 记录以期限"隔夜"写入逆回购数据

#### Scenario: 标题与正文合并

- **WHEN** 表格标题与正文句子连在一起
- **THEN** 仍能按关键字识别交易类型并完成解析

### Requirement: 中文落款日期必须正确解析

正文没有阿拉伯数字日期、仅有中文数字落款时，解析出的月与日 MUST 正确，MUST NOT 把"十月"解析为 1 月。

#### Scenario: 中文落款

- **WHEN** 落款为"二〇二五年十月十三日"
- **THEN** 解析结果为 2025 年 10 月 13 日

### Requirement: 快讯接口异常状态必须显式失败

快讯接口返回的业务状态码非成功时，任务 MUST 抛出明确错误使执行失败，MUST NOT 以空结果继续后续处理。

#### Scenario: 接口返回非零状态

- **WHEN** 快讯接口返回的业务状态码不为 0
- **THEN** 该次执行失败，错误信息包含状态码

### Requirement: 需要的表在首次执行时自动创建

任务执行前 SHALL 创建缺失的表；对已存在的表 MUST NOT 修改其结构；建出的结构 MUST 与既有冻结模型的字段一致，使现有 Web 端能直接读取新写入的数据。

#### Scenario: 空库首次执行

- **WHEN** 数据库中缺少任务需要的表
- **THEN** 系统自动建表并完成入库

#### Scenario: 表已存在

- **WHEN** 数据库中已存在同名表
- **THEN** 系统不修改表结构，直接写入数据

#### Scenario: 结构一致性

- **WHEN** 用冻结模型与新的建表语句各建一个空库并逐表比对
- **THEN** 表名、字段与主键定义没有差异
