# Spec Delta

## Purpose

定义任务执行失败后的固定次数重试、状态持久化与邮件告警分级，使失败可感知、可恢复，且不会因为进程重启或告警渠道异常而丢失。

## ADDED Requirements

### Requirement: 失败后按固定次数重试

执行失败时系统 SHALL 按任务注册声明的重试次数与间隔再次执行；重试次数 MUST 有上限，MUST NOT 无限重试。

#### Scenario: 首次失败后重试成功

- **WHEN** 某次执行失败且剩余重试次数大于 0
- **THEN** 系统在声明的间隔后再次执行，成功后该次运行记为成功

#### Scenario: 重试次数用尽

- **WHEN** 某次运行的重试次数已用尽且仍然失败
- **THEN** 该次运行标记为最终失败，不再自动重试

#### Scenario: 未声明的重试参数

- **WHEN** 任务注册未声明重试次数与间隔
- **THEN** 系统使用默认值执行，且默认值在运行时配置中可见

### Requirement: 重试状态必须持久化

待重试状态 MUST 写入运行账本；进程在重试间隔内重启后，待重试的记录 MUST 继续被处理，MUST NOT 丢失。

#### Scenario: 重试等待期间进程重启

- **WHEN** 某次运行失败并等待重试时进程被重启
- **THEN** 重启后该记录仍按原计划继续重试，尝试次数不重置

#### Scenario: 重试不阻塞其他任务

- **WHEN** 某任务处于重试等待中
- **THEN** 其他到期任务仍按顺序正常执行，不被该任务阻塞

### Requirement: 不可回溯任务的失败立即告警

声明为不可回溯的任务，每次执行失败时 MUST 立即发送邮件告警，MUST NOT 等到重试结束才通知。

#### Scenario: 不可回溯任务首次失败

- **WHEN** 不可回溯的任务执行失败
- **THEN** 系统立即发送告警邮件，并在重试前完成发送

#### Scenario: 不可回溯任务重试仍失败

- **WHEN** 不可回溯的任务在重试过程中再次失败
- **THEN** 每一次失败都发送告警邮件

### Requirement: 可回溯任务的告警在重试耗尽后发送

声明为可回溯的任务，执行失败时 SHALL 先重试；只有在重试次数用尽后 MUST 发送一次最终失败告警。

#### Scenario: 可回溯任务首次失败

- **WHEN** 可回溯的任务首次执行失败
- **THEN** 系统只记录状态并进入重试，不发送告警邮件

#### Scenario: 可回溯任务重试耗尽

- **WHEN** 可回溯的任务重试次数用尽仍然失败
- **THEN** 系统发送一封最终失败告警邮件

### Requirement: 错过触发导致的丢失必须告警

不可回溯的任务因停机错过触发而被标记丢失时，系统 MUST 发送告警，说明该次数据已无法补齐。

#### Scenario: 不可回溯任务错过触发

- **WHEN** 不可回溯的任务在停机期间错过一次触发
- **THEN** 系统恢复后发送"数据已不可补"告警，并在账本中保留该丢失记录

### Requirement: 告警内容足以定位问题

告警邮件 MUST 包含任务标识、计划触发时间、已尝试次数、失败原因摘要，以及该任务是否可补；MUST NOT 包含数据库连接凭据等敏感信息。

#### Scenario: 收到失败告警

- **WHEN** 维护者收到一封失败告警邮件
- **THEN** 邮件中能直接判断是哪个任务、哪次计划、失败原因，以及是否还有补跑机会

### Requirement: 告警渠道异常不得影响任务执行

邮件发送失败时系统 MUST 记录告警失败并继续按既定策略重试任务，MUST NOT 因告警失败改变任务本身的执行结果。

#### Scenario: SMTP 不可达

- **WHEN** 任务失败需要告警，但 SMTP 服务器连接失败
- **THEN** 任务的重试与状态流转照常进行，告警失败被记录在日志与账本中

### Requirement: 告警凭据不得进入版本库

SMTP 账号、授权码与收件人 MUST 从本地未提交的配置读取；仓库中 MUST 只保留不含真实凭据的示例文件。

#### Scenario: 检查仓库

- **WHEN** 检查版本库中的告警配置
- **THEN** 只存在占位值的示例文件，不存在真实账号或授权码

#### Scenario: 本地未配置告警

- **WHEN** 启动时本地配置缺少 SMTP 参数
- **THEN** 系统给出明确提示并按"不发送告警"运行，其余功能不受影响
